The Two-Layer Instrument
The harness sees only what production could deploy. Scoring sees what production never can.
What the harness sees
JSON schema validation. Domain invariants: line items sum to the total, counts match, dates parse. The visible test suite. Everything here is deployable by a real team today.
What only scoring sees
Gold answer values. Hidden edge case tests. Never shown to any model, used only to grade the experiment after the fact.
Uncaught error
passes everything the harness can check, fails ground truth. The kind that ships.
This gap is the quantity the entire token debate has no instrument for.

The Real Axis
Workloads split on verification cost, not task difficulty. The premium is earned only in one column.
Verifiable + routine
Extraction, classification, templated code. Schema and tests check it. Already migrating.
cheap tier now
Hard to verify + routine
Summaries, short analysis. Build golden sets and invariants, then migrate.
build the check
Verifiable + hard
Large refactors, complex codegen. Tests still check it. Qualify on frontier, then pin down.
qualification lane
Hard to verify + hard
Legal reasoning, strategy, open ended judgment. Checking needs frontier judgment itself.
premium earned
CHEAP TO VERIFY EXPENSIVE TO VERIFY
Coding pays the labs today and commoditizes first, for the same reason: it is the most verifiable work there is.
